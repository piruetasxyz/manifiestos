# manifiestos

## Don Buchla, 1971, poema

transcrito desde libro The Composer's Black Box, por Theodore Gordon, páginas 88 a 89

```txt
WHAT THE MACHINE CAN AFFORD
AND PRODUCE IS A NEW LANGUAGE
CULTIVATING AND REFINING
IN THE LISTENER A NEW SENSE
OF PERCEPTUAL MECHANICS WHEN
THE LISTENER IS ALSO THE
OPERATOR-CREATOR HIS VISUAL
AND AUTO-MUSCULAR SENSES ADD
TO HIS INTERPRETIVE MODEL
OF THE UNFOLDING AUDITORY
PROCESS THE OPERATOR
FUNCTIONS IN A SPECIAL
RELATIONSHIP TO HIS OWN
PERCEPTUAL FEEDBACK SYSTEM
 A SYSTEM IN WHICH THE MACHINE
FUNCTIONS AS A CRITICAL
INTERFACE WITHIN THE CIRCULAR
CIRCUIT CRITICAL THRESHOLDS
EXCEEDED ENABLING
BIOCOMPUTER TO ACHIEVE
INTERLOCK WITH HARD-
WARE COMPUTER THE
PROGRAM AS A PATCH-UP
AND SET OF SETTINGS
OF DIALS AND SWITCHES
REPRESENTS A SCORE
BUT A SCORE WHICH IS
VARIABLE GESTURE-
EXPRESSION-MEANING-
LOGIC-STRUCTURE-STATEMENT
ARE ARRIVED AT THROUGH
CYCLES OF INPUT AND OUTPUT
```

traducción a español por Aarón Montoya-Moraga, octubre 2026

```txt
LO QUE LA MÁQUINA PUEDE PERMITIR
Y PRODUCIR ES UN NUEVO LENGUAJE
CULTIVANDO Y REFINANDO
EN LA ESCUCHANTE UN NUEVO SENTIDO
DE MECÁNICA PERCEPTUAL CUANDO
LA ESCUCHANTE ES TAMBIÉN
LA OPERADORA-CREADORA SUS SENTIDOS
VISUALES Y AUTO-MUSCULARES AGREGAN
A SU MODELO INTERPRETATIVO
DEL PROCESO AUDITORIO
QUE SE DESENVUELVE
EL OPERADOR FUNCIONA
EN UNA RELACIÓN
ESPECIAL A SU PROPIO SISTEMA
DE RETROALIMENTACIÓN PERCEPTuAL
 UN SISTEMA EN EL QUE LA MÁQUINA
FUNCIONA COMO UNA INTERFAZ CRÍTICA
DENTRO DE LOS UMBRALES CIRCULARES
CRÍTICOS DE LOS CIRCUITOS
EXCEDIDOS PERMITEN
A LA BIOCOMPUTADORA LOGRAR
ENTRELAZADO CON EL HARDWARE
DE LA COMPUTADORA EL PROGRAMA
COMO UNA CONFIGURACIÓN
DE PERILLAS E INTERRUPTORES
REPRESENTA UNA PARTITURA
PERO UNA PARTITURA QUE ES
VARIABLE GESTURAL-
EXPRESIVA-SIGNIFICADO-
LÓGICA-ESTRUCTURA-ENUNCIADO
ARRIBAN ENTRE CICLOS
DE ENTRADAS Y SALIDAS
```
